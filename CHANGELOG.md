# Changelog

## [Unreleased]

## 1.0.1 - 2026-10-29
### Fixed
- Подключение к obs-websocket больше не зависит от системного прокси (`ClientWebSocket.Options.Proxy = null`), повтор подключения каждую секунду.

### Added
- Ошибки подключения пишутся в `ObsFrame.log` рядом с программой (до 256 КБ).

## 1.0.0 - 2026-10-29
### Added
- Окно «Записи OBS» (кнопка «☰ Видео»): список видео из папки записей OBS с датой, длительностью и размером; воспроизвести, показать в папке, переименовать (F2), удалить в корзину (Del), автообновление.
- Ключ `--with-obs`: запускает OBS, если он не запущен; ярлык «OBS + рамка» на рабочем столе и «Рамка OBS» в «Пуске» используют его.
- Кнопка «✕» на панели для закрытия рамки; ярлык «Рамка OBS» в меню «Пуск» для повторного запуска.

## 0.1.0 - 2026-10-29
### Added
- Рамка вокруг записываемой области OBS с цветом по состоянию: ожидание, запись, пауза ([ObsFrame.cs](ObsFrame.cs)).
- Панель управления: таймер, размер файла, Запись/Стоп, Пауза/Продолжить, папка с записями.
- Перенос и изменение размера области мышью с применением в OBS через obs-websocket.
- Исключение окон рамки из захвата экрана; автозапуск через папку «Автозагрузка».
